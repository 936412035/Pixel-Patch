像素补丁 · AI 区域换图工具 v0.20.1
============================

启动方式
1. 双击“启动-区域换图工具-v0.20.1.cmd”。
2. 软件会像旧版一样直接打开本地 index.html，不会再等待代理启动；若系统找不到 Edge，会改用默认浏览器打开。
3. 启动脚本会同时在后台运行仅监听 127.0.0.1:17837 的 AI API 代理。页面会自动重试连接；如显示未连接，可点击代理状态再次检测。
4. 即使代理没有启动，普通裁切、贴图、蒙版和 Lab 校色仍可正常使用；只有 AI 自动校色按钮会暂时停用。

软件更新
- 每次启动后都会读取公开仓库中的静态 version.json 检查版本，不再调用有每小时次数限制的 GitHub REST API；发现新版时，左上角版本号旁会显示“NEW”小框。点击版本号或“NEW”可查看更新。
- 发现新版时会显示版本说明。只有点击“下载并安装”后才会修改本地文件，不会静默更新。
- 更新包必须带有同名 .sha256 校验文件；软件会在安装前验证 SHA-256，并把当前文件备份到 .updates 文件夹。
- 安装失败会自动恢复原版本。安装完成后页面和本地代理会重新载入。
- 公开仓库更新不需要 GitHub Token，也不会使用你填写的 AI API Key。
- 软件优先从 raw.githubusercontent.com 读取版本清单，失败时改用 jsDelivr 镜像；安装包仍从 GitHub Releases 下载并进行 SHA-256 校验。
5. 只有点击“AI 自动校色”时，选区图片才会经本地代理发送给你选择的平台。

推荐流程
1. 载入原图。
2. 用鼠标框出需要 AI 修改的区域。
   按住 Shift 拖动可强制框选 1:1 正方形。
   框选完成后，拖动框内或边缘可移动选区；拖动四个角可改变大小。自由比例下，角点缩放时按住 Shift 会锁定当前比例。
   也可以从常用比例中选择 1:1、4:3、3:4、3:2、2:3、16:9、9:16 或 21:9。
3. 点击“导出选区 PNG”，把这张局部图交给 AI 修改。
4. 将 AI 结果拖入右侧入口，或复制图片后在软件里按 Ctrl+V。
   导入 AI 图片后，右侧四页调整面板才会出现。
5. 选择“铺满裁切”或“完整放入”，拖动贴图并调整缩放、透明度、旋转、羽化。
6. 选择“蒙版笔刷”，用“恢复原图”擦除 AI 图片多余区域；也可切到“画入 AI”补回。
7. 可按住“查看原图”对比，或使用软件顶部的按钮隐藏绿色方框检查最终效果。
8. 点击右上角“导出完整图片”输出单层 PNG；点击“导出 PSD”输出包含“Original”和“AI Result”两个栅格图层的 PSD。AI 图层会固化软件中的位置、缩放、旋转、透明度、蒙版和校色结果，并保持与画布一致的坐标。

快捷操作
- S：框选模式
- V：移动贴图模式
- B：蒙版笔刷模式
- 鼠标滚轮：缩放画布
- 空格 + 左键拖动 / 鼠标中键拖动：平移画布
- 方向键：贴图移动 1 像素
- Shift + 方向键：贴图移动 10 像素
- Alt + 方向键：贴图移动 0.1 像素
- Ctrl+V：从剪贴板粘贴 AI 图片
- Ctrl+Z：回退贴图或蒙版调整，最多保留 20 步
- 数值标题左右拖动：快速调整对应数值

右侧三页
- 位置大小：默认“完整放入”；调整对齐、缩放、透明度、旋转、羽化和位置。右侧数值框可直接键入精确数值；透明度下方可按住按钮查看原图。
- 蒙版画笔：点击此页签会自动切换为画笔，不再需要左侧画笔按钮。鼠标悬停画面时显示真实笔触范围；调整大小或不透明度时，画面中央会以白色实时预览笔触。
- 色彩调整：可在本机使用 Lab 算法自动匹配原选区，也可分别调整 L 亮度、a 红绿、b 黄蓝、饱和度和色温。
- 色彩调整中的 AI 模式可选择 OpenAI、通义千问（阿里云百炼）、MiniMax / 海螺、Lovart 或自定义 OpenAI 兼容接口。填写接口、模型和 API Key 后，软件会根据测得色差自动生成提示词，并显示进度和完成状态。
- OpenAI 默认使用 https://api.openai.com/v1/images/edits 与 gpt-image-2。
- 通义千问默认使用 qwen-image-2.0-pro。需要把接口地址中的 {WorkspaceId} 替换为阿里云百炼控制台中的工作空间 ID，软件会把本地图片转换为 Base64 后发送。
- MiniMax / 海螺默认使用 image-01。其官方图像参考接口目前要求图片是公网 URL，因此选择该平台后还需填写“待校色图公网 URL”和“原选区参考图公网 URL”。该接口属于参考生成，不保证只改变颜色或像素级保持构图。
- Lovart 的公开站点目前没有稳定、完整的统一图像编辑请求格式。软件会保留可编辑的接口地址和模型，并按 OpenAI 兼容 multipart 格式发送；请以你的 Lovart 工作区 API 文档为准。
- API Key、公网图片 URL 只存在当前页面内存，不写入项目文件或浏览器存储。API 请求由 127.0.0.1 本地代理发送，从而避免浏览器 CORS 跨域失败。
- AI 校色完成后，可打开“显示 AI 校色前”开关比较处理前后的结果。远程平台返回的错误会由本地代理显示在进度状态中。
- 本地代理只允许 HTTPS 远程接口，并拒绝访问 localhost、局域网和私有 IP；OpenAI、千问、MiniMax 选项还会校验官方 API 域名。
- 绿色选区框、完整 PNG 和分层 PSD 的导出按钮位于软件顶部，不再占用右侧页签。

关于画质和颜色
- 输出默认为 PNG，不会产生 JPEG 二次压缩。
- 软件只在选区内合成 AI 结果，选区以外沿用原图像素，不会跟随 AI 图片降低分辨率。
- 大分辨率原图会自动生成轻量显示预览，框选和缩放使用预览，PNG/PSD 导出仍读取原始像素。
- 若边缘需要自然融合，可少量增加“边缘羽化”。
- 浏览器会按标准 sRGB 显示和导出图片；印刷用 CMYK/特殊 ICC 工作流仍建议使用专业色彩软件复核。

项目文件
- 选区会按原图文件特征自动保存在当前电脑的浏览器中。
- “保存项目”会生成 JSON，记录选区和贴图调整参数（不内嵌大图片）。
- 读取项目后，请按提示重新载入对应原图和 AI 图。
